# Original Unit Unlimbo and factory scope controls

`mission --unit-unlimbo` preserves nine direct MTNK placement controls and eight
whole original Building `0x00443C60` controls. `unit_entry --counter-mode`
preserves eight independent class controls. The same Mission mode also records
eight actual Unit Limbo/reused Stage controls, six selected bool-reader histories
and seven factory radio-8 fixtures with nine calls, plus six authored HIGH/scope
controls. They execute identity-checked retail
`gamemd.exe`, SHA-256
`1cdd1180e49024fbda8ad568caac2e86e856063ff67ab38f62b7d2c7bb84298c`,
with the existing Mission and Unit entry fixtures. These are bounded native
executions; the Python checks alone do not establish Rust parity.

## Reproduction and source identity

Activate the project's native-oracle environment and supply the existing admitted
physical extract roots. `VERA20K_ANYTOWN_INPUTS` selects the Anytown manifest;
`VERA20K_SHRAPNEL_INPUTS` supplies the inherited RULESMD/ARTMD/MPBattleMD and
selected sound/SHP inputs. Their file hashes, sections and original reader
receipts remain in each Mission row. See [the physical packet](README.md) and
[input owner](inputs.py) for preparation; retail assets are not stored here.

```sh
source /Users/halvor/Documents/vera20k-dev/env.sh

PYTHONPATH=. PYTHONDONTWRITEBYTECODE=1 python -m tools.spatial_oracle.unit_entry_boundary --check
```

## Corpus boundaries

`unit_unlimbo.json` has `{schema_version, native_sha256, direct_rows,
factory_rows, visceroid_reader_receipt, stage_rows, factory_exit_radio_rows,
authored_rows}`.
Every direct row retains `input`, `before`, `after`,
`returned_al`, `trace`, all three full RNG objects, geometry startup and inherited
physical input receipts. The new `after_unlimbo` snapshot is taken immediately
after original `0x00737BA0` returns, before the fixture's assertion or frame-1
Attack command. Its `actor` adds `on_bridge` and `in_playfield` to Mission's
state, with `stage_and_timer`, raw `occupation` and ordered `lists` beside it.
Historical `after` includes the later command for admitted controls and must not
be used as an immediate placement golden. Timer word `+0x104` is recorded raw
padding; it is not an authoritative timer field.

Direct/factory `stage_before` and `stage_after` compose the existing
`FootMissions.stage_clock_snap` decoder: `{value, changed, timer:{start,
aux_raw_u32, duration}, rate, increment, raw_stage_bytes}`. The reader receipt
records original UnitType constructor defaults, native literal key addresses
and six cached-section histories. The actual `747862..74789C`/`5295F0` calls
produce all values; no Python bool answer is substituted. Its sequence
`yes/no -> missing -> no/true` checks current-byte defaults across later layers.

Eight `stage_rows` first perform the ordinary original constructor/placement,
then the fixture's frame-1 Attack command, then original Unit Limbo `7440B0`.
The same actor is poisoned with Stage value77, changed1, timer start-7/duration19,
rate-3/increment5 and raw auxiliary word `0x13579BDF`. Four retained Small/Large
flag combinations and raw ground0/32 select admitted/refused second Unlimbo at
frame123. Rows retain actual Limbo and initial-placement receipts, immediate
second-call actor/Stage snapshots, full RNG bytes, and `rng_before`/`rng_after`
through the existing state decoder for serde transport. The poison values and
MTNK bool overrides are explicit inputs; their production is not claimed.

Direct cases vary raw ground/deck `0x20`, independent scope/actual mode,
HasBridge, caller OnBridge and requested deck Z. Original Unit geometry startup
`735180/735210/735230/735250/7352F0` runs from executable constants before
construction. The reader receipts and before/after bytes are saved, including
full RNG equality. Original Unit/Foot/Techno/Object constructors and Unlimbo,
class admission, Mark, Cell/Recalc, sight and Logic/Display registration execute.

Factory rows retain the whole controller return, fresh actor prestate, final
actor state, final counter, actual producer constructor/read fields and vtable
slots, producer missions, native PC/counter/actor trace, selected Cell raw/list
state, events and full RNG objects. `GAWEAP` uses original constructors and
selected native physical layered Naval, Weeder, Refinery, WeaponsFactory,
ExitCoord and ART Foundation readers. ExitCoord is `[512,256,0]`; Foundation is
the original reader's `5x3` identity. Full producer Type reader/loading is not
claimed: its separate failed visual-loader diagnostic is excluded.

Five active GAWEAP controls cover clear/raw-busy, actual mode 1, nested scope 3
and HasBridge with a ground caller pose. Two inactive-Scenario controls execute
the actual refusal and unwind; they are not ordinary live factory failures.
The eighth control deliberately passes MTNK to GAYARD. It reaches the original
naval arm without the land counter bracket, but is **invalid retail naval
production**. It cannot demonstrate legal Ship/FNPC production or naval
placement completion.

`unit_entry_counter_mode.json` contains eight rows with `input` (kind, counter,
actual mode and original fixture), the first-call receipt, measured second-call
result, native trace, three full RNG objects and text hash. The fixture is owned
by `unit_entry.query`; no retained VM monkeypatch or second controller is used.
The measured call follows native seeding with 31 for each stream. Supplied
retained playfield/LocalSize controls and nonhuman CrateType controls isolate
the two original globals; initialization of those prestates is outside this
corpus. Scratch owner bytes remain unchanged across each measured class call.

Seven `factory_exit_radio_rows` compose a fresh original successful GAWEAP
factory call with original Contact0 `65ACB0` opcode8. The preserved external
shape is `{input, factory, supplied_post_factory_data, primary}`, plus
`healthy_scope0.already_cleared` and
`null_sender_without_contacts.preliminary`. Each call saves both endpoint
contact vectors/tethers, missions, timers, body/turret facing, XYZ, full RNG,
instruction branches, nested message returns and true return sites. Scopes0/1/3
stay unchanged. A caller slice executes original `73A936..73A946` through the
reply comparison, excluding its earlier gates and later per-cell work.
Absent-Unit-contact and NULL-sender cases are explicit adversarial boundaries;
Helipad/UnitRepair distance, repair, docking and BuildingUnload are excluded.

Six `authored_rows` retain a fresh original Unit constructor, execute the actual
`7434EC..743514` HIGH branch, then execute `7435C6..7435D6` through the original
virtual `+D8` Unlimbo call. Their external shape is preserved: `{input, before,
pre_unlimbo, returned_al, after, stage_after, raw_after, lists_after, trace, rng,
text_sha256, inherited_inputs, geometry_startup}`. `pre_unlimbo` saves the actual
requested XYZ and OnBridge, counter, initialized bridge-height constant, Cell
level/flags and Drive `+50` identity. The inherited field name
`drive_activate_slot50` means ForceSlope `4B04D0`; no extra height activation is
implied. `after` is the immediate Unit return, with no later Attack command.
`lists_after` records the native Cell `+E4/+E8` heads; it is not selected from
HIGH or a Rust plane. Full three RNG objects are unchanged.

Four rows vary parsed HIGH0/1 and HasBridge false/true while both raw planes
hold `0x20` and scope is2. HIGH0 requests `[22400,12928,0]` with OnBridge0 and
finishes at Z416. HIGH1 requests Z832 with OnBridge1 and finishes there, even
without HasBridge. Two scope0 controls use a busy selected plane and observe
the original refusal. They are counter controls, not ordinary authored-load
scope. Parsed HIGH EAX, centered XY/Z0, actor register, facing128 and Cell/counter
data are supplied. Complete tokenization/atoi, House/type lookup and Scenario
loading are excluded.

## Native ownership and ordering

Original Object `5F3900` initializes Location by copying the shared default
coordinate: `5F3993/5F399F` read/write X from `AC1380`, `5F39A5/5F39AB` copy Y
from `AC1384`, and `5F39AE/5F39C0` copy Z from `AC1388` into `+9C/+A0/+A4`.
The original initializer `5F38A0` uses `XOR EAX,EAX`, then writes those three
globals at `5F38A2/5F38A7/5F38AC`. CRT data slot `814204` points to it. The
metadata saves original bytes/hashes for these static receipts; this fixture
does not execute the complete CRT traversal. A cell-center offset128 is not
part of this constructor Location. The complete original Unit constructor
retains `[0,0,0]` before the measured placement.

| Unit `7353CE`, Infantry `517A5B`, Aircraft `413D2B` | Foot `4D31E0` |
| Foot `4D31EA`, Building `43B74B` | Techno `6F2B40` |

Ordinary Terrain `71BB90` later invokes Terrain Unlimbo `71D000` from its
supplied Cell, so its whole constructor is not evidence of a held limbo object.
Caller staging of a position after construction is likewise distinct from the
fresh Object default. Raw Rust fixtures or APIs that intentionally stage a
later position must preserve that separate caller action; the native default
does not authorize clearing arbitrary retained limbo state.

`A8E7AC` is a nested scope counter. Object Unlimbo `5F4F1B` reads it to skip
ordinary class admission; Unit `73F34C` and Infantry `51C144` read it for their
retained-playfield boundary branches. Actual GameMode is **`A8B238`**: Unit's
later nonhuman crate branch reads it at `73F405`. The existing Unit entry key
`game_mode_nonzero` has always written `A8E7AC`; it remains a compatibility alias
for that counter. New explicit fields separate these values, and the old
boundary corpus retains identical inputs/results with corrected metadata.

## Explicit seams

Mission supplies one human House after null-House construction and a physical
cropped map. Full House/Scenario loading, AddTracking/bookkeeping, producer
foundation publication, global phases and other active objects are excluded.
Bridge controls supply HasBridge/OnBridge/Z; authored bridge materialization,
later bridge movement and lifetime remain separate mechanisms. The same native
admission result must not be used to invent caller pose authority.

Inherited physical INI caches, heap/file mappings, OS ASCII/CLSID/Ole/Interlocked/
SEH/CRT/setup services and visual/radar/sound sinks remain. Drive activation
routes to its original factory. Connectivity executes; whole-map hierarchy
remains the inherited callback. Independent class fixtures clone a Unit vtable
in scratch, retaining original class `+1AC`; scatter-only Queue/Set observer
slots are never reached. Original executable/vtable tables are unchanged.
The new modes do not replace any selected gameplay admission, RNG, timer,
Mark/radio/queue or Unlimbo return.
